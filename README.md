# Command Line habit tracker

## To try the program:
- open terminal or command prompt
- navigate to a desired location
    - e.g, `cd ~ && mkdir apps && cd apps`
- clone the repository
    - `git clone <repo link>`
- run `pip install -r requirements.txt`
- run using `python3 main.py`
- Enjoy!
